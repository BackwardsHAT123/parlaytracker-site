# parlaytracker.app

Landing, support and privacy pages for the Parlay Tracker iOS app. Plain HTML/CSS/JS, no build step.
Font: Barlow and Barlow Condensed (SIL Open Font License, see assets/fonts/Barlow-OFL.txt), Latin subset.
The hero slip's confetti and tear are ports of the app's ConfettiDrawing.swift and TearDrawing.swift.
